# AI-Assisted UVM Verification & Regression Platform

A portfolio project for verifying a custom SystemVerilog AXI4-Lite peripheral.

## Planned components

- SystemVerilog AXI4-Lite peripheral DUT
- UVM verification environment
- Constrained-random testing
- Functional coverage
- SystemVerilog assertions
- Python regression automation
- AI-assisted failure analysis
- Streamlit dashboard

## Development environment

- Ubuntu on WSL2
- Git
- Python
- GNU Make
- GCC
